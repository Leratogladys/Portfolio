Matric Connect

A learner-focused application concept for exploring institutions and checking matric results against programme requirements.

01 · The problem

Make programme requirements easier to understand.

Prospective students often need to compare their results with requirements that differ between programmes. Matric Connect is being developed to bring programme information and learner results into one workflow, with the aim of making eligibility checks easier to interpret.

02 · Eligibility logic

Rules should reflect each programme.

The planned eligibility workflow compares learner marks with the selected programme's requirements. Subject-specific checks should only apply when the programme requires that subject; a missing subject should not automatically disqualify a learner from every programme.

Learner marks→Programme rules→EligibilityService
03 · Technology

Current implementation direction.

The project uses C#, ASP.NET Core MVC, Entity Framework Core and SQLite. It is in development. Features such as a broader institution dataset, bursary tracking, REST API integration and PostgreSQL support should be treated as planned work unless confirmed in the implementation.
