Taxi Fare Calculator

A practical mobile application designed to make shared taxi fare calculations clearer for South African commuters, particularly when one passenger pays for a group.

DART / FLUTTER / PROVIDER / MVVM
Try live demoView source code
01 · The problem

Make the numbers easier to follow.

When a passenger pays for more than one person, the calculation can involve the group fare, the amount handed over and the change that must be returned. The app brings those values together so the result is easier to check.

The project focuses on a straightforward commuter task rather than adding unnecessary steps to the journey.

02 · Application structure

Separating interface from application logic.

The application is built with Flutter and Dart. It uses an MVVM-oriented structure and Provider for state management, keeping UI concerns separate from the calculations and state consumed by the interface.

VIEW

Collects passenger and payment inputs and presents the calculation.

VIEWMODEL

Coordinates UI state and exposes values for the view.

MODEL

Represents the fare and payment data used by the calculation.

03 · Example calculation

04 · Next steps

Room to extend the application.

Future improvements can include persistent trip or fare records and additional validation around passenger counts and payment inputs. These are potential extensions, not features represented here as complete.
